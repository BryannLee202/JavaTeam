# JavaTeam — SHMS (SEAL Hackathon Management System)

Nhánh `main` đã được dọn về trạng thái trống để cả nhóm xây frontend lại từ đầu
trong đợt xây lại frontend.

> Toàn bộ code cũ (backend, bff, frontend cũ, SRS, docker-compose) vẫn còn nguyên
> ở nhánh **`main-backup`**. Xem lại: `git checkout main-backup`

## Cách làm việc

Mỗi người làm trên nhánh của mình, xong thì mở Pull Request vào `main`.
Chỉ merge sau khi đã review.

| Phần việc | Nhánh | Người phụ trách |
|---|---|---|
| Nền tảng + xác thực quản trị     | `JAV-9-nen-tang`            | Phạm Nguyễn Hoài Long |
| Landingpage + Bảng kết quả       | `JAV-11-cong-khai`          | Lê Minh Tài |
| Coordinator + cấu trúc cuộc thi  | `JAV-12-cau-truc-cuoc-thi`  | Nguyên Tạ Huỳnh |
| Chấm điểm + Hiệu chuẩn           | `JAV-13-cham-diem`          | Toàn Huỳnh Thúc |
| Đội thi và mentor                | `JAV-14-doi-thi`            | Trần Thị Yến Vy |
| Tiêu chí chấm + giải thưởng      | `JAV-15-tieu-chi`           | Lê Minh Tài |
